Nine Lives Editor

Build in the world, add people, write quests and conversations, and change items, loot and shops.

Start here

1Open BuildThe Build tab shows the world in 3D. It starts by itself (or press ▶ Start at the top right). There's no character: you fly around.
2Place thingsIn Assets at the bottom, click a thing or a person, then click in the 3D view to put it down. Drag it, or right-click it for more.
3SaveSave (Ctrl+S) keeps your changes as packs in the game's Mods folder. Undo (Ctrl+Z) and Discard take them back.

How changes reach the game
  1. Save in the editor (Ctrl+S). Changes are kept as packs in the game's Mods folder.
  2. Play with the Play Nine Lives Offline shortcut: switched-on packs load when the game starts.
  3. In Build, the 3D view shows placed things, NPCs, dialogue and scripts as you change them.
  4. Quests and items load when the game starts. With DevTools in a running game: F7, then reloadquests or reloadcontent.
