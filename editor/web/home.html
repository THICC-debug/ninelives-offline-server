How changes reach the game
  1. Save in the editor (Ctrl+S). Changes are kept as packs in the game's Mods folder.
  2. Start the game: packs load when it starts.
  3. Game already running? With DevTools, press F7 and type reloadquests, reloadcontent or npcreload.
