# ExampleMod (template)

A starter mod, not meant for release. It logs a greeting and shows a Harmony patch working.

To make your own mod, copy this folder to `mods/YourMod`, rename the `.csproj`, `.cs`,
class and Harmony ID, and follow [MODDING.md](../../MODDING.md). Copy the `Version` and
`Package` parts from [TravelMod.csproj](../TravelMod/TravelMod.csproj) when you want to release it.
